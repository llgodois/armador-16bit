# Roadmap — Armador 16-bit

Plano combinado para as próximas versões, em **6 levas**. Cada leva é feita numa sessão nova e termina com o jogo testável.
Estimativa total: ~11.000 linhas novas (o jogo tem ~5.300 hoje) e ~0,7–1,2 milhão de tokens.

**Regras de design que valem para tudo**
- Você sempre controla o **armador** (ataque e defesa). Quem você marca **pode trocar** (bloqueios, transição), mas o jogador controlado nunca muda.
- O centro do jogo é **ler a jogada**: toda mecânica nova deve recompensar a boa leitura.
- Fora do escopo: versão para celular; editor de liga/comissário. O editor de jogador/uniforme só existe no modo carreira, para o seu personagem.
